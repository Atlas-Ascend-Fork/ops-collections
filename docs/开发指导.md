## 二、项目架构

### 2.1 分层架构设计

ops-collections采用分层架构设计，从主机端到设备端分为多层：

```sh
┌─────────────────────────────────────────┐
│          应用层                          │
│    StaticMap / StaticMapRef             │
├─────────────────────────────────────────┤
│          实现层                          │
│    OpenAddressingImpl                   │
├─────────────────────────────────────────┤
│          组件层                          │
│  ProbingScheme | Storage | Hash         │
├─────────────────────────────────────────┤
│          基础层                          │
│    Pair | Extent | Allocator            │
└─────────────────────────────────────────┘
```

**架构说明：**

- **应用层**：提供容器类，StaticMap 为主机端容器，提供 Insert、Find、Erase 等算子接口；StaticMapRef 为设备端内部实现
- **实现层**：基于开放寻址法的哈希表实现
- **组件层**：探测策略、存储管理、哈希函数等可配置组件
- **基础层**：基础数据结构和工具类

## 五、算子开发实例

本节以StaticMap的Insert算子为例，详细介绍如何基于ops-collections开发算子，包括架构分析、开发步骤、测试方法等。

### 5.1 Insert算子架构分析

Insert算子采用分层架构设计，从主机端到设备端分为三层：

```sh
主机端API层 (StaticMap::Insert)
    │
    ├── 参数校验和初始化
    ├── Kernel启动配置
    └── 流同步和结果返回
            │
            ▼
Kernel入口层 (Insert Kernel)
    │
    ├── 线程索引计算
    ├── StaticMapRef构造
    └── 数据分发处理
            │
            ▼
设备端实现层 (StaticMapRef::Insert)
    │
    ├── 哈希计算
    ├── 探测策略
    ├── 原子操作CAS
    └── 冲突处理
```

### 5.2 开发步骤详解

#### 5.2.0 调用链概览

Insert算子的完整调用链如下：

```sh
用户代码
    │
    └─→ StaticMap::Insert (include/static_map.h，实现见 include/detail/static_map/static_map.inl)
            │
            └─→ OpenAddressingImpl::Insert (include/detail/open_addressing/open_addressing_impl.h)
                    │  转发到 InsertIf<ValueType, AlwaysTrue>（同文件）
                    │
                    └─→ aclco::InsertIf Kernel (include/detail/open_addressing/kernels.h)
                            │
                            └─→ InsertIfSimt（SIMT VF 函数，同文件）
                                    │
                                    └─→ StaticMapRef::Insert (include/static_map_ref.h，实现见 include/detail/static_map/static_map_ref.inl)
                                            │
                                            └─→ OpenAddressingRefImpl::Insert → InsertVerdict (include/detail/open_addressing/open_addressing_ref_impl.h)
```

**各层职责：**

- **`StaticMap::Insert`**：用户接口，提供类型安全的API
- **`OpenAddressingImpl::Insert`**：实现层入口，直接转发到 `InsertIf<ValueType, AlwaysTrue>`；`InsertIf` 负责参数校验、kernel启动和结果收集
- **`aclco::InsertIf` Kernel**：NPU kernel入口，通过 `VF_CALL` 启动SIMT向量函数
- **`InsertIfSimt`**：SIMT VF 函数，负责线程分配与数据分发
- **`StaticMapRef::Insert`**：设备端引用，封装实现细节
- **`OpenAddressingRefImpl::Insert`**：`InsertVerdict` 的包装；探测循环在 `InsertVerdict` 中，执行具体的插入逻辑

#### 5.2.1 步骤一：用户接口层（StaticMap::Insert）

用户接口层提供类型安全的API，将调用转发到实现层。

**代码位置：** `include/static_map.h`

**接口声明：**

```cpp

```

**实现代码：** `include/detail/static_map/static_map.inl`

```cpp

          class T,
          class Extent,

          class Storage>
```

**关键点：**

- 将调用转发到实现层`impl_`
- 保持类型安全和接口简洁

#### 5.2.2 步骤二：实现层（OpenAddressingImpl::Insert → InsertIf）

实现层入口 `Insert` 直接转发到 `InsertIf<ValueType, AlwaysTrue>`，由后者完成参数校验、kernel启动和结果收集。

**代码位置：** `include/detail/open_addressing/open_addressing_impl.h`

**实现要点：**

```cpp
SizeType Insert(void *values, Extent valueNum, aclrtStream stream)
{
    return InsertIf<ValueType, AlwaysTrue>(values, values, valueNum, stream);
}

template <typename StencilT, typename Predicate>
SizeType InsertIf(void *values, void *stencil, Extent valueNum, aclrtStream stream)
{
    // 1. 参数校验
    if (valueNum == 0) { return 0; }
    if (values == nullptr) { return valueNum; }
    if (stencil == nullptr) { return valueNum; }

    // 2. 初始化失败计数器
    argStorage_.Initialize(0, stream);

    // 3. 获取AIV核数并启动kernel
    auto aivCoreNum = platform_ascendc::PlatformAscendCManager::GetInstance()->GetCoreNumAiv();
    aclco::InsertIf<KeyType, ValueType, bucketSize, ProbingScheme, KeyEqual, StencilT, Predicate>
        <<<aivCoreNum, 0, stream>>>(
        (uint8_t*)storage_.Data(),      // 哈希表指针
        (uint8_t*)values,                // 待插入数据指针
        (uint8_t*)stencil,               // 掩码指针（Insert 时 AlwaysTrue 恒通过）
        (uint8_t*)emptyValueStorage_.Data(), // 空值指针
        storage_.Capacity(),             // 表容量
        valueNum,                        // 数据数量
        (uint8_t*)argStorage_.Data());   // 失败计数器

    // 4. 同步流并返回结果
    uint32_t ret = aclrtSynchronizeStream(stream);
    CheckRet(ret, "StaticMap::InsertIf::aclrtSynchronizeStream");
    return argStorage_.LoadToHost(stream);
}
```

**关键点：**

- `Insert` 转发到 `InsertIf<ValueType, AlwaysTrue>`，`AlwaysTrue` 谓词使掩码恒通过，语义等价于无条件插入
- 参数校验确保输入合法性
- `argStorage_`用于统计插入失败的数量
- 使用AIV核进行并行计算
- 同步等待kernel执行完成

#### 5.2.3 步骤三：Kernel入口实现

Kernel入口负责线程分配和数据分发。

**代码位置：** `include/detail/open_addressing/kernels.h`

**实现要点：**

```cpp
template <typename Key, typename Value, uint32_t BucketSize,
          typename ProbingScheme, typename KeyEqual, typename StencilT, typename Predicate>
COLLECTION_SIMT_VF LAUNCH_BOUND(THREAD_NUM_LAUNCH_BOUND) inline void InsertIfSimt(
  __gm__ uint8_t *table, __gm__ uint8_t *values, __gm__ uint8_t *stencil, __gm__ uint8_t *emptyValue,
  uint32_t tableSize, uint32_t valueNum, __gm__ uint32_t *insertFailedNum)
{
    // 1. 计算全局线程索引
    uint32_t blockIndex = AscendC::Simt::GetBlockIdx();
    uint32_t blockNumber = AscendC::Simt::GetBlockNum();
    uint32_t globalThreadIdx = blockIndex * AscendC::Simt::GetThreadNum()
                               + AscendC::Simt::GetThreadIdx();
    uint32_t totalThreadNum = blockNumber * AscendC::Simt::GetThreadNum();

    // 2. 构造设备端引用（Map/Set 按值类型自动选择）
    using StorageRefType = aclco::BucketStorageRef<Value, BucketSize>;
    using ProbingSchemeType = ProbingScheme;
    using RefType = typename std::conditional<!isPairV<Value>,
      StaticSetRef<Key, KeyEqual, ProbingSchemeType, StorageRefType>,
      StaticMapRef<Key, KeyEqual, ProbingSchemeType, StorageRefType>>::type;

    StorageRefType tableRef = StorageRefType(tableSize, (__gm__ Value*)table);
    ProbingSchemeType probingScheme = {};
    KeyEqual keyEqual = {};
    Predicate pred = {};
    RefType ref(*((__gm__ Value*)emptyValue), keyEqual, probingScheme, tableRef);

    // 3. 循环处理数据（每个线程处理多条数据；掩码不通过则跳过）
    uint32_t localFailed = 0;
    for (uint32_t i = globalThreadIdx; i < valueNum; i = i + totalThreadNum) {
        StencilT stencilValue = *((__gm__ StencilT*)(stencil) + i);
        if (!pred(stencilValue)) { continue; }
        Value insertValue = *((__gm__ Value*)(values) + i);
        if (!ref.Insert(insertValue)) {
            localFailed += 1;
        }
    }
    // 4. 每线程寄存器累加失败数，循环末一次全局原子加（避免高重复批次序列化）
    if (localFailed != 0) {
        AscendC::Simt::AtomicAdd(insertFailedNum, localFailed);
    }
}

template <typename Key, typename Value, uint32_t BucketSize,
          typename ProbingScheme, typename KeyEqual, typename StencilT, typename Predicate>
COLLECTION_AIV_GLOBAL void InsertIf(__gm__ uint8_t *table, __gm__ uint8_t *values,
                                    __gm__ uint8_t *stencil, __gm__ uint8_t *emptyValue,
                                    uint32_t tableSize, uint32_t valueNum,
                                    __gm__ uint8_t *insertFailedNum)
{
    AscendC::Simt::VF_CALL<InsertIfSimt<Key, Value, BucketSize, ProbingScheme, KeyEqual, StencilT, Predicate>>(
        AscendC::Simt::Dim3{DEFAULT_THREAD_NUM},
        table, values, stencil, emptyValue, tableSize, valueNum,
        (__gm__ uint32_t*)insertFailedNum);
}
```

**关键点：**

- `aclco::InsertIf` 是 AIV kernel入口，通过 `VF_CALL` 启动SIMT向量函数 `InsertIfSimt`
- 使用SIMT编程模型，每个线程处理一个或多个数据项
- 通过`globalThreadIdx`和`totalThreadNum`实现数据分发
- 构造`StaticMapRef`/`StaticSetRef`对象用于设备端操作（按值类型是否为Pair自动选择）
- 失败数先在线程内寄存器累加，再一次性原子加，减少原子操作竞争

#### 5.2.5 步骤五：设备端核心实现（OpenAddressingRefImpl::Insert → InsertVerdict）

设备端实现负责具体的插入逻辑，包括哈希计算、探测策略、原子操作等。`Insert` 是 `InsertVerdict<false>` 的薄包装，探测循环在 `InsertVerdict` 中。

**代码位置：** `include/detail/open_addressing/open_addressing_ref_impl.h`

**接口包装：**

```cpp
template <typename Value>
COLLECTION_SIMT_DEVICE bool Insert(Value value)
{
    return InsertVerdict<false>(value) == InsertResult::SUCCESS;
}
```

**实现要点（探测循环，`InsertVerdict`）：**

```cpp
template <bool assign, typename Value>
COLLECTION_SIMT_DEVICE InsertResult InsertVerdict(Value value)
{
    __gm__ Value* tableHandle = storageRef_.Data();
    SizeType tableSize = storageRef_.Capacity();
    auto const key = this->ExtractKey(value);

    // 1. 创建探测迭代器
    auto probingIter = probingScheme_.template MakeIterator<bucketSize>(key, tableSize);
    auto const initIdx = *probingIter;

    while (true) {
        __gm__ Value* bucketSlotsAddr = tableHandle + *probingIter;

        // 2. 遍历桶内的每个槽位
        for (size_t i = 0; i < bucketSize; i++) {
            auto const slotContent = *(bucketSlotsAddr + i);

            // 3. 检查键是否相等或槽位可用
            EqualResult insertFlag = predicate_.template operator()<IsInsert::YES>(
                key, this->ExtractKey(slotContent), this->ExtractKey(emptySlotValue_));

            if (insertFlag == EqualResult::EQUAL) {
                if constexpr (assign) {
                    AssignPayload(bucketSlotsAddr + i, value);
                }
                return InsertResult::DUPLICATE;  // 键已存在
            }

            if (insertFlag == EqualResult::AVAILABLE) {
                // 4. 尝试原子CAS插入
                InsertResult result;
                if constexpr (assign) {
                    result = AttemptInsertOrAssign(bucketSlotsAddr + i, emptySlotValue_, value);
                } else {
                    result = AttemptInsert(bucketSlotsAddr + i, emptySlotValue_, value);
                }
                if (result != InsertResult::FAILED) {
                    return result;
                }
            }
        }

        // 5. 移动到下一个探测位置
        ++probingIter;
        if (*probingIter == initIdx) {
            return InsertResult::FAILED;  // 表已满
        }
    }
}
```

**关键点：**

- `Insert`（`assign=false`）返回是否新插入成功；`InsertOrAssignVerdict`（`assign=true`）在键已存在时更新payload
- 返回三态 `InsertResult`：SUCCESS（新插入）、DUPLICATE（键已存在）、FAILED（表已满）
- 使用探测策略解决哈希冲突
- 使用原子CAS操作保证线程安全
- 检查键的相等性和槽位可用性

**原子操作实现：**

```cpp
template <typename Value>
COLLECTION_SIMT_DEVICE InsertResult AttemptInsert(__gm__ Value *address,
                                             Value expected,
                                             Value desired) noexcept
{
    if constexpr (sizeof(Value) <= 8) {
        return PackCas(address, expected, desired);
    } else {
        return BackToBackCas(address, expected, desired);
    }
}

// 对于小于等于8字节的值，使用打包CAS
template <typename Value>
COLLECTION_SIMT_DEVICE InsertResult PackCas(__gm__ Value *address,
                                       Value expected,
                                       Value desired) noexcept
{
    using PackedType = typename Conditional<sizeof(Value) == 4, uint32_t, uint64_t>::Type;

    __gm__ auto *slotPtr = reinterpret_cast<__gm__ PackedType*>(address);
    auto *expectedPtr = reinterpret_cast<PackedType*>(&expected);
    auto *desirePtr = reinterpret_cast<PackedType*>(&desired);

    auto oldSlot = AscendC::Simt::AtomicCas(slotPtr, *expectedPtr, *desirePtr);
    auto *oldSlotPtr = reinterpret_cast<Value *>(&oldSlot);

    if (this->predicate_.EqualTo(this->ExtractKey(expected),
                                  this->ExtractKey(*oldSlotPtr)) == EqualResult::EQUAL) {
        return InsertResult::SUCCESS;
    } else {
        if (this->predicate_.EqualTo(this->ExtractKey(desired),
                                      this->ExtractKey(*oldSlotPtr)) == EqualResult::EQUAL) {
            return InsertResult::DUPLICATE;
        }
        return InsertResult::FAILED;
    }
}
```

### 5.4 开发新算子的步骤总结

基于Insert算子的开发经验，开发新算子的步骤如下：

1. **需求分析**
   - 明确算子功能
   - 确定输入输出参数
   - 设计同步/异步接口

2. **架构设计**
   - 确定分层架构（用户接口层、实现层、Kernel层、设备端实现层）
   - 设计数据流和控制流
   - 确定并发策略

3. **主机端实现**
   - 在`StaticMap`类中添加接口声明
   - 在实现层添加具体实现
   - 处理参数校验和错误处理

4. **Kernel实现**
   - 编写Kernel入口函数
   - 实现线程分配逻辑
   - 构造设备端引用对象

5. **设备端实现**
   - 在`StaticMapRef`中添加设备端接口
   - 在`OpenAddressingRefImpl`中实现核心逻辑
   - 使用原子操作保证线程安全

6. **测试验证**
   - 编写单元测试
   - 编写性能测试
   - 验证正确性和性能

7. **文档编写**
   - 更新API文档
   - 添加使用示例
   - 编写开发说明
